# 🎰 Колесо Депа

Веб-игра в стиле казино, созданная на чистом HTML/CSS/JS.

## 🔗 Демо
[Открыть игру](https://твой_никнейм.github.io/koleso-depa/)

## 🛠 Стек
- HTML5, CSS3 (Grid, Flexbox, анимации)
- Vanilla JavaScript (ES6+)
- LocalStorage, Web Audio API

## 🎮 Фичи
- 14 мини-игр (рулетка, слоты, блэкджек, покер и др.)
- Кастомная математика с преимуществом казино
- Система золота и NFC-ваучеров
- Адаптивный дизайн
